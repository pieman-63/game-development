First Game Project

The first project is a simple combat-oriented game designed as a starting point for exploring game mechanics, player progression, procedural elements, and basic game logic.

Core Concept

The player has a set of health and other statistics and encounters enemies whose statistics are generated dynamically.

The basic gameplay loop revolves around:

1. Creating an enemy with randomized statistics.
2. Fighting the enemy using the game's combat mechanics.
3. Gaining experience from defeated enemies.
4. Leveling up to improve the player's overall statistics.
5. Potentially gaining increases to specific player statistics when an enemy possesses a significant or major stat.
6. Managing a pool of available points to create, allocate, and confirm the player's statistics.
7. Continuing the run until the player's health reaches zero.

Planned Mechanics

- Player Health (HP) — The player's run ends when health reaches zero.
- Randomized Enemies — Enemy statistics are generated dynamically rather than being completely predefined.
- Combat System — A basic fight mechanic forms the core gameplay loop.
- Experience & Levels — Defeating enemies grants experience and allows the player to level up.
- Stat Progression — Leveling provides an overall improvement to the player's statistics.
- Major Stat System — Certain enemies may have a main/major statistic that can influence the player's progression.
- Stat Allocation — The player receives points that can be used to build and confirm their statistics.
- Run-Based Progression — The player's current run ends when their health reaches zero.

The system is intentionally simple at first. More complex mechanics can be introduced as the project develops.
